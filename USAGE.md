# Add Two Numbers Script

This project includes a Python script, `add_two.py`, that adds two numbers supplied as command-line arguments.

## Requirements

- Python 3.8+

## Usage

Run the script with two numbers:

```bash
python3 add_two.py <number1> <number2>
```

### Examples

Add integers:

```bash
python3 add_two.py 5 7
```

Output:

```text
12
```

Add decimal values:

```bash
python3 add_two.py 2.5 3.1
```

Output:

```text
5.6
```

## Notes

- The script accepts integers and floating-point numbers.
- If the result is a whole number, the script prints it without a decimal point.
